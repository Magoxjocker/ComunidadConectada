# Requerimientos

| ID | Requerimiento y aceptación |
| --- | --- |
| RF-01 | Registro y recuperación por correo. Nombre, vivienda, contraseña confirmada, verificación y habilitación administrativa. |
| RF-02 | Aprovisionamiento mediante Admin SDK. Los permisos administrativos se aplican en cliente, servidor y reglas. |
| RF-03 | Inicio personalizado, vivienda, avisos destacados, novedades y SOS. |
| RF-04 | Chat general en tiempo real con autor, vivienda, fecha del servidor, historial y mensajes propios. |
| RF-05 | Marketplace con búsqueda, filtro, detalle, edición, eliminación y cambio de estado por propietario. |
| RF-06 | Anuncios ordenados por prioridad y fecha. CRUD administrativo y notificación FCM al publicar. |
| RF-07 | SOS confirmado y persistido. MQTT con TLS, QoS 1, reconexión, deduplicación y estados diferenciados. |
| RF-08 | Encuestas con alternativas, plazo, cierre, privacidad y voto único por residente. |
| RF-09 | Reportes privados por residente. Administración gestiona estados, observaciones e historial. |
| RF-10 | Perfil, cierre de sesión, escalado de texto, modo oscuro y alto contraste. |
| RNF-01 | Java, XML, Gradle Groovy, API 26 mínima, Material 3, MVVM y repositorio. |
| RNF-02 | TLS, control por UID, aislamiento, validaciones y credenciales administrativas externas al APK. |
| RNF-03 | Interfaz en español de Chile. WCAG 2.2 AA y recomendaciones Android como referencias. |
| RNF-04 | Estados de carga, errores, reintentos idempotentes y evidencias de pruebas. |

El mercado usa fichas textuales. Incorporar fotos requiere almacenamiento y autorización por propietario.
